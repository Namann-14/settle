# .vercelignore

**Purpose:** Keeps local env files and local DB files out of Vercel deployments.

**Key contents:** Excludes `.env*` (except `.env.example`), `local.db*` and `.alchemy/`.

**Depends on / used by:** Used by Vercel deploys of the monorepo.

**Decisions & caveats:** Vercel project env vars are the source of truth. Shipping local `.env` files would make Next.js load localhost values at runtime, so this exclusion matters.
