# .gitignore

**Purpose:** Root git ignore rules for the monorepo.

**Key contents:** Ignores dependencies, build output, env files, editor/log files, Next.js and Python caches, Turbo/Vercel/alchemy state, and locally installed agent skills (`.agents/`, `.claude/skills/`).

**Depends on / used by:** Applies repo-wide; `apps/web/.gitignore` and `apps/fumadocs/.gitignore` add app-specific rules.

**Decisions & caveats:** `apps/web/src/routeTree.gen.ts` is ignored, a leftover from a TanStack Router setup the web app no longer uses. `.env*` is ignored at the root, so env templates must be force-added or whitelisted per app. `services/api/Python/` (local installer cache) is ignored too.
