# apps/web/src/components/groups/group-detail.tsx

**Purpose:** Single group page: figures, quick add, expenses / settlements / members, balances, AI insight and settle plan.

**Key contents:** `GroupDetail` builds `PageContainer` > "All groups" back link > `PageHeader` (group name, "N members · currency · description", Settle up + Add expense) > `GroupFigures` (`FigureStrip`: your balance, payments to settle up, members) > `AiQuickAdd` > two-up grid: a `Segmented` tab switch over `GroupExpenses` / `GroupSettlements` / `GroupMembers` panels, and a side column with `BalancesPanel` and `GroupInsightPanel` > `SettlePlanCard`. Members panel holds invite-by-email, `JoinLinkCard`, member rows (Admin marked in the name line, Leave/Remove) and pending invites with Cancel. Exports `GroupDetailSkeleton` (used by the route's `loading.tsx`).

**Depends on / used by:** Uses `dashboard/panel.tsx` primitives, `useGroup`, `useGroupBalances`, `useGroupInvitations`, `useGroupInsight`, `useExpenses`/`useSettlements` (`group_id`, limit 100; match the route prefetch), `join-link-card.tsx`, `expense-sheet.tsx`, `ai-quick-add.tsx`, `settlements/*` (`SettlementRow`, `SettlePlanCard`, `RecordSettlementDialog`), `myImpact` from `expenses-page.tsx`.

**Decisions & caveats:** Every list owns a row-shaped skeleton, an inline "Try again" on error and a one-line empty state. The insight is a normal panel ("Group insight · From Settle AI"), not a dark special card, and its narrative is body text, not serif. Inviting never adds anyone: the copy says the invite waits for them to accept, and pending rows read "Waiting to accept". The cancel button shows only to the inviter or an admin, matching the api rule. Admin rights are derived client-side from the active member list (`role === 'ADMIN'`); the API remains the real enforcement. Quick-add is locked to this group. Large file mixing several concerns; split before adding more. The settle plan (`SettlePlanCard`) sits in the side column under Balances, and the Balances panel no longer repeats the simplified payments list (it duplicated the plan).
