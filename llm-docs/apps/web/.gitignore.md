# apps/web/.gitignore

**Purpose:** Git ignore rules for the web app.

**Key contents:** Ignores deps, Next/Vercel/OpenNext build output, `.env*` (keeping `.env.example`), logs, `next-env.d.ts` and IDE files.

**Depends on / used by:** Complements the root `.gitignore`.

**Decisions & caveats:** Contains leftover entries from other frameworks (vinxi, tanstack, wrangler, nitro).
